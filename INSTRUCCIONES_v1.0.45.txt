     (conserva las rutas: package.json, src\, scripts\, tests\, index.html).
  2. En esa carpeta:
       npm install
     Debe descargar electron 44.9.3 y electron-builder 26.15.3 (~120 MB la

  3. Comprueba que responde:
       npx electron-builder --version
     Esperado: 26.15.3
  4. npm run build
  5. npm run dist
