# CerebróNico Full Stack Developer

Suite completa de herramientas para desarrollo web full stack con CerebróNico. Incluye creación de sitios web, refactorización segura, auditoría de calidad y optimización de rendimiento.

## ¿Qué incluye?

### 1. Creación de Sitios Web
- **cerebronico-creador**: Crear sitios web accesibles y optimizados
- **cerebronico-creador-bucle**: Construcción autónoma de sitios
- **cerebronico-web-qa**: Auditoría web completa (WCAG, rendimiento, SEO)

### 2. Desarrollo Backend
- **cerebronico-api**: Diseño y consumo de APIs REST

### 4. Herramientas DevOps

- **cerebronico-observabilidad**: Logs y métricas

## Ejemplos de Uso

### Crear un Sitio Web
```bash
# 1. Elegir plantilla disponible
plantillas_disponibles

# 2. Crear sitio con el brief
crear_sitio {
  "nombre": "mi-proyecto",
  "tipo": "negocio",
  "titulo": "Mi Proyecto",
  "subtitulo": "Descripción del proyecto",
  "caracteristicas": [
    {"titulo": "Característica 1", "texto": "Descripción"},
    {"titulo": "Característica 2", "texto": "Descripción"}
  ]
}

# 3. Auditar y mejorar
auditar_pagina "mi-proyecto/index.html"
mejorar_pagina "mi-proyecto/index.html" aplicar: true

# 4. Convertir a PWA
crear_pwa "mi-proyecto"
crear_og_image "mi-proyecto"
```

### Refactorizar un Proyecto
```bash
# Refactor seguro multi-archivo
cerebronico-refactor {
  "accion": "extraer-funcion",
  "archivo": "src/components/Componente.jsx",
  "funcion": "manejarSubmit",
  "destino": "src/utils/formUtils.js"
}
```
