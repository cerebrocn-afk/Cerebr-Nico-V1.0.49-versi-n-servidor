Webflow MCP Server

Integración de Webflow con CerebroNico vía Model Context Protocol.

Estado: Sin OAuth

Para activar, necesitas una cuenta Webflow y completar OAuth.

Qué permite

  • Gestionar sitios Webflow desde el chat
  • Operar con colecciones CMS e items
  • Modificar componentes y propiedades del DOM
  • Registrar scripts inline en sitios

Configuración

Servidor MCP remoto: https://mcp.webflow.com/mcp

Requiere Node.js 22.3.0+ y cuenta Webflow activa.

Ver documentación oficial.

Modo puente MCP

En mcp_servers.json del proyecto:

{
  "id": "webflow",
  "label": "Webflow: diseño y gestión (requiere OAuth)",
  "comando": "npx",
  "args": ["-y", "webflow-mcp-server"],
  "enabled": false,
  "timeout": 30
}
